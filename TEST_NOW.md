## All Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Enter** | Advance to next (or submit on last) |
| **Shift+Enter** | Newline in long_text (doesn't advance) |
| **Arrow Up** | Go back to previous question |
| **Arrow Down** | Advance to next question |
| **Tab** | Navigate form elements |
